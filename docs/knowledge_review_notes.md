## 已处理（原「存疑，未改」8 条，来源经 WebSearch/WebFetch 核对）
1. **十四大财阀** → 改为「主要财阀」。结论：各资料数字不一（辞典称10财阀/财阀家族56人，论文称指定持株会社83社、家族56人），没找到支持「十四」的来源。来源：[kotobank 財閥解体](https://kotobank.jp/word/財閥解体)、[横浜国大学术论文](https://ynu.repo.nii.ac.jp/record/2095/files/KJ00004763241.pdf)。
2. **病院记号** → 改为「＋外围五边形（源自旧陆军卫生队标志）」。结论：国土地理院说明病院记号源自旧陆军卫生队的标志，未见「红十字/盾牌形」的依据；外国人向け资料称现行记号是「＋」被五角形围住。来源：[国土地理院 地図記号：病院](https://www.gsi.go.jp/KIDS/map-sign-tizukigou-2022-byouin.htm)。同时核实上一轮改动：[警察署](https://www.gsi.go.jp/KIDS/map-sign-tizukigou-2022keisatusho.htm)=圆圈内交叉警棍，[交番](https://www.gsi.go.jp/KIDS/map-sign-tizukigou-2022-kouban.htm)=不带圆圈；[畑](https://www.gsi.go.jp/KIDS/map-sign-tizukigou-2022-hatake.htm)=二叶（嫩芽）形，均与现文一致。
3. **濑户内降水<1000mm、含广岛** → 改为「较少（冈山约1100mm、高松约1100mm上下）」，并去掉广岛。结论：气象厅1991–2020平年值冈山1143.1mm、广岛1572.2mm（来源：[气象厅 岡山](https://www.data.jma.go.jp/obd/stats/etrn/view/nml_sfc_ym.php?prec_no=66&block_no=47768&year=&month=&day=&view=)、[广岛](https://www.data.jma.go.jp/obd/stats/etrn/view/nml_sfc_ym.php?prec_no=67&block_no=47765&year=&month=&day=&view=)）；高松只找到1981–2010的非官方汇总值1082mm，故写「约1100mm上下」。
4. **OPEC 巴西括号** → 按指示直接删除（时事，未查）。
5. **故乡纳税与法人二税** → 拆开：法人二税句保留，故乡纳税改述为「个人向自治体捐赠、可抵扣个人住民税等的制度」。来源：[总务省 ふるさと納税など個人住民税の寄附金税制](https://www.soumu.go.jp/main_sosiki/jichi_zeisei/czaisei/czaisei_seido/080430_3_kojin.html)。
6. **尊属杀** → 按最高裁1973.4.4大法廷判旨改写：加重本身不违宪，但仅死刑/无期的加重程度过大、与普通杀人显失均衡，违反宪法14条1款。来源：[law-lib.jp 判例解说](https://law-lib.jp/subjects/1/precedents/46)、[Wikibooks 刑法第200条](https://ja.wikibooks.org/wiki/%E5%88%91%E6%B3%95%E7%AC%AC200%E6%9D%A1)。
7. **气候描述与 Cfb 口诀** → 日本海侧/中央高地的定性说法无明确错误，保持原样；仅两处收紧：Cfb 口诀去掉「50~100mm」具体数字（来源只支持「全年降水较均匀」，[TUFS 教材](https://www.tufs.ac.jp/documents/institutions/ojec/projects/jsl/geography-general/general_212.pdf)、[Weblio](https://www.weblio.jp/content/Cfb)），改为「大致均匀、无明显干季」；中央高地「日较差与年较差极大」只有年较差（寒暖差）有来源（[大阪府教材](https://www.pref.osaka.lg.jp/documents/25642/sya_1tiri_7_2hoju_kai.pdf)），改为「年较差大」。
8. **英国首相解散权** → 保持原样。理由：2011年固定任期议会法已被2022年《Dissolution and Calling of Parliament Act 2022》废止，君主的解散特权（实际由首相建议行使）恢复，现文正确。来源：[legislation.gov.uk](https://www.legislation.gov.uk/ukpga/2022/11/enacted)。
