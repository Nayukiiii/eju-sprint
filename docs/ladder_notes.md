# 阶梯学习（先修路径）备忘

- 数据：`ladder_data.js`（概念 + 真题→概念）、`ladder_cards.js`（新写的先修卡，`lad-` 前缀）；逻辑：`ladder.js`；app.js 里只有 `window.EJU_LADDER_HOOK` 的 4 处钩子和 `window.EJU_APP` 接口。
- 校验：`node tools/ladder_check.js`（概念 id、先修卡存在、新卡 id 不重复、152 题标注覆盖）。
- 概念「已掌握」＝其全部先修卡 `box ≥ 1` 且最近一次评分为「掌握」（不用 box ≥ 2：一轮先修每张卡只推进一级，要求 2 级就永远解锁不了）。
- 真题「已做对」＝同样的判定。「我已会，直接做」存在 localStorage `eju-ladder-v1`，不进同步数据。
- 先修卡正解位置按 id 固定打散（`ladder_cards.js` 里的 `L()`），选项顺序和书写顺序不同。

## 存疑 / 注意
- 带图的题（地图、统计图表、地形图、雨温图等）没有逐张看原卷图片，概念是按题面+解析里的文字标的（例如 2023第1回 02/04/05/07/10/20/23/24，2023第2回 03/04/05/08/16/19/20/21/22/23/24，2024 03/04/05/07/13/18/20/23，2025 01/04/06/07/13/17/19/20/21/22/24）。概念本身是对的，但卡片不教「怎么读那张图」。
- 所有 152 题都标了概念，没有留空的；个别题（如 2025 第 1 题水泥、2024 第 13 题债务比）只给了背景概念，先修卡不能直接让人做对图表题。
- 部分概念只有 1～2 张先修卡（该概念本身简单，或题库里已有同主题自编题）。
- 先修卡只写教科书层面的确定事实；与真题同一事实点相近的题（如「法の支配」「ベルリン会議」）已刻意避免把原题答案原句放进先修卡，但个别概念不可避免地会提到答案所在的知识点。
